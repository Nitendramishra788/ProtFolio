
# 🚀 Portfolio - Full Stack MERN Portfolio & Admin Dashboard

A modern full-stack portfolio web application with a powerful admin dashboard built using the MERN Stack.
This project allows dynamic management of projects, skills, profile information, and contact messages through a secure admin panel.

---

# ✨ Features

## 🌐 User Portfolio

* Dynamic Hero Section
* Dynamic Skills Section
* Dynamic Projects Section
* Contact Form Integration
* Responsive Modern UI
* Animated Components
* Backend API Integration

---

## 🔐 Admin Dashboard

### Authentication

* Admin Login System
* JWT Authentication
* Protected Routes
* Secure Token-Based Authorization

### Profile Management

* Create Profile
* Update Profile
* Dynamic Profile Image
* About & Message Section

### Skills Management

* Add Skills
* Edit Skills
* Delete Skills
* Dynamic Skills Rendering

### Projects Management

* Add Projects
* Edit Projects
* Delete Projects
* Image Upload Support
* Live & GitHub Links

### Message Management

* View Messages
* Delete Messages
* Mark Read / Unread
* Email Reply Support

# ⚙️ Installation Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Nitendramishra788/ProtFolio.git
```

---

## 2️⃣ Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

### Admin Panel

```bash
cd admin
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside backend folder.

```env
PORT=3000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY

EMAIL_USER=YOUR_EMAIL

EMAIL_PASS=YOUR_APP_PASSWORD
```

---

# ▶️ Run Project

## Backend

```bash
npm run dev
```

## Frontend

```bash
npm run dev
```

## Admin

```bash
npm run dev
```

# 📡 API Routes

## Auth Routes

```bash
POST /api/auth/login
```

---

## Profile Routes

```bash
GET /api/profile
PUT /api/profile
```

---

## Skills Routes

```bash
GET /api/skills
POST /api/skills
PUT /api/skills/:id
DELETE /api/skills/:id
```

---

## Projects Routes

```bash
GET /api/projects
POST /api/projects
PUT /api/projects/:id
DELETE /api/projects/:id
```

---

## Message Routes

```bash
POST /api/messages
GET /api/messages
PUT /api/messages/:id
DELETE /api/messages/:id
```
